# Maze Generation and Recursive Pathfinding

## Что делает программа
- Генерирует лабиринт случайным образом
- Ищет путь от старта (S) до выхода (E)
- Показывает лабиринт и путь в терминале

## Как запустить
1. Убедись, что установлен Python
2. Открой терминал
3. Введи:python3 main.py
